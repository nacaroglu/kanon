# Incident Response

Treat any customer-visible outage as an incident.

## Declaring an incident

Post in the incident channel using the template:

```
# Incident: <service>
Impact: <who is affected>
```

The on-call engineer becomes the incident commander.

## Escalation

If the incident is not mitigated within 30 minutes, page the engineering manager.
